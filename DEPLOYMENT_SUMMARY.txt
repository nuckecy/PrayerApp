  3. Wait for setup completion
  4. Copy Project URL and Anon Key from Settings → API
  5. Save these values safely

STEP 2: Connect to Vercel (5 minutes)
──────────────────────────────────────
Location: https://vercel.com/dashboard
Actions:
  1. Add environment variables:
     - NEXT_PUBLIC_SUPABASE_URL = [copy from Supabase]
     - NEXT_PUBLIC_SUPABASE_ANON_KEY = [copy from Supabase]
  2. Set Root Directory to: ./frontend
  3. Trigger redeploy
  4. Wait for build completion

STEP 3: Test Your App (5 minutes)

  3. Verify user appears in Supabase dashboard
  4. Test login functionality
  5. Done! ✅
