# Vercel Configuration

This configuration tells Vercel to build the Next.js app from the `frontend` directory.

## Important Notes

- The root `vercel.json` is for GitHub integration deployment
- The `frontend/vercel.json` is for CLI deployment from within the frontend directory
- When deploying via Vercel dashboard, **also set Root Directory to `frontend`** in project settings

## Monorepo Structure

```
PrayerApp/
├── vercel.json          # Root config for GitHub integration
├── frontend/            # Next.js app
│   ├── vercel.json     # Frontend-specific config
│   └── package.json    # Has Next.js dependency
└── backend/            # Fastify API
```
